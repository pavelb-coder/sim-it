# sim-it — тренажёры для IT-квантума

Браузерные тренажёры для занятий в IT-квантуме: без установки, без регистрации, без интернета.
Устроены как среда, а не как курс с видео: ученик пишет код, сразу видит результат, получает
автопроверку и «приборы» — те же механики, что в хороших браузерных симуляторах, только для IT.

## Что уже работает

**8 тренажёров, 85 задач.** Каталог: **https://pavelb-coder.github.io/sim-it/** — оттуда открывается
любой продукт. Каждый тренажёр — отдельный автономный HTML-файл со своей теорией, рабочей областью,
автопроверкой и сохранением прогресса.

Открыть: скачать файл `python-class/dist/python-class.html` и дважды щёлкнуть. Больше ничего не нужно.

## Проверки

```bash
python3 build_site.py                          # пересобрать все продукты и каталог
cd python-class && ./test.sh                   # тесты движка Python
python3 products/cpp/tests/run_tests.py        # тесты мини-компилятора C++
```

C++ проверяется двумя способами: эталонные решения всех 8 задач против их тестов и
**дифференциальный тест с настоящим `g++`** — 15 программ прогоняются и через g++, и через
наш интерпретатор, вывод сравнивается построчно (нужен установленный g++, иначе шаг пропускается).

* 48 конструкций языка сверяются с настоящим CPython — совпадение построчное;
* все 39 эталонных решений проходят все свои тесты (в движке и в CPython — 162 прогона);
* интерфейс прокликивается в jsdom (`npm i jsdom`), включая работу без `localStorage`;
* готовый CI лежит в [`docs/ci-tests.yml.example`](docs/ci-tests.yml.example) — скопировать в
  `.github/workflows/tests.yml` (для пуша нужен токен со scope `workflow`).

## Запуск

### 1. Онлайн, прямо из GitHub (ничего устанавливать не нужно)

GitHub Pages отдаёт тренажёр как обычный сайт:

**https://pavelb-coder.github.io/sim-it/** — открыть в любом браузере, в том числе на планшете.

Публикуется автоматически из ветки `main`. `index.html` в корне — каталог линейки, а каждый
продукт лежит в своей папке (`python/`, `terminal/`, `network/`, `web/`, `sql/`, `security/`, `ai/`).
Всё это собирается командой `python3 build_site.py`.

### 2. Windows

Дважды щёлкнуть **`start.bat`** (или из консоли: `start.bat`, можно указать другой порт: `start.bat 8090`).

Скрипт сам выбирает, чем поднять сервер:
1. `py -3` → 2. `python` → 3. встроенный сервер PowerShell (`tools/serve.ps1`) → 4. если ничего нет,
открывает файл напрямую.

Откроется браузер на **http://localhost:8087/**.

### 3. Ubuntu / Linux / macOS

```bash
./start.sh            # порт 8087
./start.sh 8090       # другой порт
```

Нужен только Python 3 (`python3 -m http.server` тоже подойдёт), запасные варианты — `npx http-server`,
`busybox httpd`. Откроется **http://localhost:8087/**.

### 4. Без сервера вообще

Открыть любой собранный файл двойным щелчком: `python/index.html`, `terminal/index.html`,
`sql/index.html` … — они полностью автономные, интернет и сервер не нужны.

### Порт

Везде по умолчанию **8087**. Меняется первым аргументом (`./start.sh 8090`, `start.bat 8090`,
`python3 tools/serve.py 8090`) или флагами:

```bash
python3 tools/serve.py --port 8087 --host 0.0.0.0 --no-open
```

Сервер слушает `0.0.0.0`, поэтому на занятии можно раздать адрес с ноутбука педагога:
`http://<ip-в-классе>:8087/` — сервер печатает этот адрес при старте. Если 8087 занят,
он предложит следующий свободный.

## Синхронизация

```bash
./scripts/sync.sh "сообщение коммита"
```

Скрипт пересобирает `dist/`, коммитит изменения и пушит в `origin/main`.
Авторизация берётся из `git credential store` (`~/.git-credentials`) или из переменной
`GITHUB_TOKEN`. Токен в репозиторий не попадает — он в `.gitignore`.

## Структура

```
sim-it/
├── index.html        каталог линейки — его отдаёт GitHub Pages
├── build_site.py     сборщик: shared/ + products/* → <продукт>/index.html
├── shared/           общая тема, шаблон страницы, каркас задач и автопроверки
├── products/         исходники продуктов: workspace.html, tasks.js, app.js, style.css
├── python/  cpp/  terminal/  network/  web/  sql/  security/  ai/    собранные тренажёры
├── python-class/     движок Python: src → build.py → dist/один файл
├── start.bat         запуск на Windows (порт 8087)
├── start.sh          запуск на Ubuntu/Linux/macOS (порт 8087)
├── tools/serve.py    локальный сервер (Python 3), порт 8087
├── tools/serve.ps1   сервер для Windows без Python
├── docs/             концепция, планы, пример CI
└── scripts/sync.sh   сборка + коммит + push одной командой
```

### Как добавить свой продукт

1. Создать папку `products/<slug>/` с обязательным `workspace.html` (разметка рабочей области),
   плюс `tasks.js` (массив задач) и `app.js` (логика + `Shell.init`). Если продукту нужен
   движок, его кладут отдельным `engine.js` — сборщик поставит его перед `app.js`.
2. В `app.js` вызвать `Shell.init({storageKey, productTitle, productSubtitle, tasks, open, check})` —
   каркас сам нарисует список задач, прогресс, подсказки и кнопку проверки.
3. Запустить `python3 build_site.py` — появятся `<slug>/index.html` и карточка в каталоге.
   Пока нет `workspace.html`, продукт в каталоге помечен «скоро».
