# Банк задач: 400 новых заданий для Python- и C++-классов

Уровень смешанный: примерно 70 % школьной программы и 30 % задач «подумать» (олимпиадные приёмы).
У каждой задачи есть теория на экран, условие, пример, подсказка, заготовка кода, эталонное решение
и скрытые тесты stdin → stdout с показом «ожидалось / получено».

Все эталоны прогнаны в настоящих CPython и `g++ -std=c++17`, ожидаемый вывод вычислен ими же,
а затем сверен с движками тренажёров — 1200 проверок без единого расхождения.

| Язык | Новых задач | Тем | Скрытых тестов | Стало задач в продукте |
|---|---|---|---|---|
| Python | 200 | 20 | 600 | 239 |
| C++ | 200 | 20 | 600 | 211 |

Проверить самому: `python3 scripts/gen_taskbank.py --check`.

## Как это собрано

* `scripts/bank/py1…py4.py` и `scripts/bank/cpp1…cpp4.py` — исходники задач, по 50 в файле;
* `scripts/taskbank_py.py` / `scripts/taskbank_cpp.py` — агрегаторы по 20 тем;
* `scripts/gen_taskbank.py` — прогоняет эталоны в настоящих `python3` и `g++`, вычисляет ожидаемый
  вывод, сверяет его с движком тренажёра и пишет `python-class/src/modules/m7…m10.js` и
  `products/cpp/tasks-bank.js`;
* `python3 build_site.py` — встраивает банк в автономные страницы продуктов.
