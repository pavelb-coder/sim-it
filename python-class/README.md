# Python-класс · тренажёр для IT-квантума

Браузерный тренажёр по Python: единая среда + «приборы» + задания с автопроверкой,
а не «курс с видео». **10 модулей, 239 задач, 762 автотеста.**

**Готовый файл:** `dist/python-class.html` — один автономный HTML на ~106 КБ.
Открывается двойным щелчком, работает без интернета, без установки и без регистрации.

---

## Что внутри

| Возможность | Как реализовано |
|---|---|
| 10 модулей, 239 задач | `src/modules/m1…m10.js`: теория на экран, условие, примеры, подсказка, эталонное решение |
| Автопроверка | у каждой задачи 3–7 **скрытых** тестов (stdin → stdout); ученик видит, что именно не совпало |
| Исполнение Python | свой интерпретатор подмножества Python 3 на JavaScript (`src/py.js`), ~1000 строк, без Pyodide и без сети |
| «Осциллограф» | вкладка **Переменные (трейс)**: пошаговое состояние всех переменных, строка за строкой |
| Прогресс | задачи открываются по порядку, прогресс и код хранятся в `localStorage` браузера |
| Режим педагога | кнопка «Открыть все задачи» — для демонстрации и свободной работы |
| Ошибки по-человечески | `NameError: имя «n» не определено (строка 7)`, защита от бесконечного цикла, подсказка про лишний/недостающий `input()` |

## Как открыть

1. **Онлайн из GitHub:** https://pavelb-coder.github.io/sim-it/
2. **Локально на Windows:** `start.bat` в корне репозитория → http://localhost:8087/
3. **Локально на Ubuntu/Linux/macOS:** `./start.sh` → http://localhost:8087/
4. Скачать `dist/python-class.html` и открыть в любом браузере (Chrome, Firefox, Edge, Safari).
2. Или положить на школьный сервер / в LMS / в Telegram-файл — это один файл без зависимостей.
5. На планшете и телефоне интерфейс перестраивается в одну колонку.

Порт по умолчанию — **8087** (`./start.sh 8090` или `start.bat 8090` для другого).

## Как добавить свою задачу

Задачи лежат по модулям: `src/modules/m1-osnovy.js` … `m6-proekt.js`.
Открой нужный файл и добавь объект в массив `tasks`:

```js
{
  id: 't11',
  title: 'Моя задача',
  subtitle: 'что тренируем',
  theory: '<p>Короткая теория на один экран, можно с <code>кодом</code>.</p>',
  prompt: 'Условие: что подаётся на вход и что вывести.',
  examples: [{ inp: '2', out: '4' }],
  level: 'средне',                     // необязательно: легко / средне / сложно
  starter: 'n = int(input())\n# допиши\n',
  tests: [
    { stdin: '2', expected: '4' },
    { stdin: '-1', expected: '1' }      // минимум 3–4 теста: константный print не должен проходить
  ],
  hint: 'Подсказка, которая помогает, но не даёт готовый ответ.',
  solution: 'n = int(input())\nprint(n * n)'
}
```

Затем `python3 build.py` — и `dist/python-class.html` пересобран.
Правило хорошей задачи: тесты должны ловить «print правильного ответа» — поэтому входные данные разные.

## Проверки

```bash
./test.sh          # всё сразу
```

* `tests/test_vs_python.js` — 48 конструкций языка прогоняются через движок и через настоящий CPython, результаты сравниваются построчно;
* `tests/test_tasks.js` — у всех 239 задач есть нужные поля, эталон проходит все свои тесты, стартовый код валиден;
* `tests/check_cpython.py` — эталоны и тесты подтверждены настоящим Python 3 (762 прогона);
* `tests/test_ui.js` — интерфейс в jsdom: запуск, проверка, трейс, прогресс, переходы (`npm i jsdom`);
Актуальный статус: **всё зелёное** — 48/48 совпадений движка с CPython, 762/762 прогонов
эталонных решений в CPython, 239/239 задач проходят автопроверку через интерфейс.

## Что движок поддерживает (и чего нет)

Поддерживается: переменные, арифметика (`//`, `%`, `**`, float), строки и методы, f-строки, срезы,
списки и методы (`sort(reverse=True)`), словари и методы, **множества** (`set`, `{1,2}`, `|`, `&`, `-`),
`if/elif/else`, `while`, `for` + `range`, генераторы списков и **генераторные выражения** в вызовах,
`def`/`return`/рекурсия, `break`/`continue`, `import math` / `import random`.

Не поддерживается (сознательно, чтобы движок оставался компактным): классы, `try/except`,
файлы, `lambda`, `*args`, `key=` в сортировке, сторонние библиотеки. На такие места выдаётся
понятное сообщение, а не «что-то пошло не так». Если в программе есть одна из этих
конструкций — ученик увидит понятное сообщение об ошибке, а не «что-то пошло не так».

**Почему свой движок, а не Pyodide:** Pyodide — это ~10 МБ загрузки и обязательный интернет.
Здесь — 106 КБ и полная автономность: работает в школьном кабинете без сети, в предпросмотре,
на слабом ноутбуке. Если понадобится «настоящий» Python с библиотеками — переключение на Pyodide
делается заменой одного вызова `PyTrainer.run()`; остальная логика не меняется.
